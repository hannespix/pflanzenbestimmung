Installation & Offline-Cache (PWA)

Die Seiten lassen sich als App zum Home-Bildschirm hinzufügen (Progressive Web App). Dazu legt ein Service Worker die Programmdateien (die vier HTML-Seiten, das Manifest und die Icons) im lokalen Cache deines Browsers ab, damit das Werkzeug auch ohne Internet startet. Dabei werden ausschließlich Dateien dieser Website gespeichert – keine personenbezogenen Daten und keine Inhalte fremder Server. Der Cache verbleibt auf deinem Gerät und lässt sich über die Browser-Einstellungen (Websitedaten löschen) jederzeit entfernen. Die Installation ist freiwillig; das Werkzeug funktioniert auch ohne sie.

Optionale Online-Funktionen

Es gibt Stellen, an denen auf deine ausdrückliche Handlung hin Daten von der Wikimedia Foundation (USA) abgerufen werden. Dabei wird jeweils deine IP-Adresse an Wikimedia übermittelt. Ohne diese Handlungen findet kein automatischer Abruf statt; alle übrigen Funktionen kommen ohne Internet aus. Es gilt die Datenschutzerklärung der Wikimedia Foundation.

  • »Online-Infos laden« im Fenster »ℹ Mehr zur Pflanze« (im Lern-Tool und im Prüfungswerkzeug): Erst auf Knopfdruck wird ein Kurztext samt Vorschaubild von der deutschen Wikipedia geladen. Der eigentliche Prüfungsbogen bleibt davon unberührt und kommt ohne Internet aus.
  • Lernmodus »Bilder« (nur im Lern-Tool): Startest du eine Sitzung in diesem Modus, werden zu den abgefragten Arten Bilder von Wikipedia bzw. Wikimedia Commons geladen (Bild-Adresse und Bildnachweis). Solange du den Modus nicht startest, passiert nichts. Die vier anderen Lernmodi (Karteikarten, Quiz, Tippen, Liste) kommen ohne Internet aus.
